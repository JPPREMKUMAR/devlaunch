# DevLaunch

A responsive developer portfolio and project showcase built with Next.js, React, TypeScript, and Tailwind CSS.

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site. Edit `components/devlaunch.tsx` to update portfolio copy, projects, skills, and links.

## GitHub

Create a repository, then commit and push the project:

```bash
git init
git add .
git commit -m "Build DevLaunch portfolio"
git branch -M main
git remote add origin https://github.com/your-name/your-repo.git
git push -u origin main
```

## Deploy to Vercel

Import the GitHub repository in Vercel, or use the Vercel CLI from the project directory:

```bash
pnpm dlx vercel
```

No database, API keys, or paid services are required.
